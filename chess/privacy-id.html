Kebijakan Privasi

Berlaku / Diperbarui: 29 September 2026

1. Operator dan lingkup

Kebijakan ini berlaku untuk aplikasi iOS “Chess” (ID paket com.osj.chess), yang diterbitkan oleh Next Studio (pengembang individu yang berbasis di Korea Selatan). Kontak: dhalska2@gmail.com. Versi Android belum dirilis.

2. Data di perangkat

Statistik, pencapaian, daftar puzzle yang terpecahkan, progres pelajaran/latihan, rentetan tantangan harian, dan pengaturan (tema papan, gaya bidak, bahasa, suara) secara default hanya disimpan di perangkatmu. Narasi suara pelatih hanya menggunakan sintesis suara bawaan perangkatmu — audio tidak pernah direkam atau dikirim ke mana pun.

3. Akun dan permainan online

Sebagian besar fitur berjalan tanpa masuk akun — aplikasi otomatis membuat akun anonim. Bermain online (pencocokan berperingkat, undangan teman) dan muncul di peringkat menyimpan nama panggilan pilihanmu, negara, avatar, lencana, dan rating di server kami, terkait dengan akun anonim tersebut. Masuk dengan Apple (opsional) membagikan alamat email melalui Apple, yang digunakan untuk autentikasi akun.

4. Pembelian dan langganan

Pembelian dalam aplikasi (hapus iklan, tema, petunjuk, undo) dan langganan (premium bulanan/tahunan) ditagih melalui App Store Apple. Kami tidak pernah menerima data pembayaranmu — server kami hanya memeriksa dan menyimpan status aktif pembelian atau langganan.

5. Sinkronisasi progres

Hanya jika kamu masuk dengan Apple, statistik, pencapaian, catatan puzzle terpecahkan, pelajaran/latihan yang selesai, catatan tantangan harian, dan skor terbaik Puzzle Rush disimpan di server kami serta digabungkan/disinkronkan di seluruh perangkatmu. Sinkronisasi ini tidak terjadi selama kamu hanya bermain secara anonim.

6. Iklan dan pilihan privasi

Layar yang tersedia gratis dapat menampilkan iklan Google AdMob. AdMob dapat mengumpulkan ID iklan, informasi perangkat, dan lokasi perkiraan (berbasis IP) untuk penayangan dan pengukuran iklan. Kamu bisa menolak iklan personalisasi lewat App Tracking Transparency iOS, atau menghapus iklan dengan pembelian dalam aplikasi.

7. Penyimpanan server dan pemrosesan lintas batas

Data akun, pembelian, permainan online, dan progres disimpan di server yang dioperasikan oleh Supabase (penyedia basis data/autentikasi kami). Server ini bisa berada di luar negeri dan diproses sesuai hukum yang berlaku di sana. Apple (penagihan App Store) dan Google (AdMob) masing-masing memproses data sesuai kebijakan privasi mereka sendiri.

8. Kontak dan penyedia situs web

Kirim pertanyaan atau permintaan penghapusan ke dhalska2@gmail.com. Halaman kebijakan ini dihosting secara statis di GitHub Pages (GitHub, Inc.); situs ini sendiri tidak menggunakan skrip analitik atau iklan sendiri.

9. Penyimpanan dan penghapusan

Data akun, pembelian, dan progres di server disimpan selama akunmu ada, dan dihapus atau dianonimkan dalam waktu yang wajar setelah permintaan penghapusan. Menghapus aplikasi menghilangkan data lokal di perangkat; data di server (jika kamu masuk akun) memerlukan permintaan penghapusan terpisah.

10. Hak pengguna, anak-anak, dan perubahan

Kamu dapat meminta akses, koreksi, atau penghapusan datamu. Aplikasi ini ditujukan untuk pengguna berusia 13 tahun ke atas dan tidak dengan sengaja mengumpulkan data pribadi dari anak-anak. Kebijakan ini dapat berubah seiring perubahan fitur; tanggal di bagian atas halaman ini diperbarui saat itu terjadi.
