首页隐私政策服务条款帮助与支持删除数据

隐私政策

生效／更新日期：2026年9月16日

1. 运营者与范围

韩国 Next Studio 运营 Hashi（com.osj.hashi）。本政策适用于应用和此支持网站。隐私联系邮箱：dhalska2@gmail.com。

2. 设备上的游戏数据

关卡进度、用时、桥梁、完成记录、撤销历史、免费提示，以及语言、主题、振动和错误显示设置保存在设备上。我们不会将完整游戏进度同步到服务器。网页预览版不提供移动广告、推送或购买功能。我们不使用独立的 Firebase Analytics 或 Crashlytics SDK。

3. 广告与隐私选择

移动应用使用 Google AdMob 插屏广告及可选的激励广告。广告 SDK 可能处理 IP 地址及据此推测的大致位置、设备和广告标识符、广告观看与点击、诊断信息及同意状态，用于广告展示、衡量和反欺诈。我们不申请精确位置权限。应用根据地区和选择显示同意提示；需要时可在设置的广告隐私选项中修改。拒绝个性化广告并不意味着停止所有技术数据处理。广告数据披露可能构成当地法律所称的“出售”或“共享”，因此我们不声称完全不收集或共享数据。可通过同意控件或邮件行使适用的退出权。 奖励广告提示仅在服务器验证 Google 的签名回调后发放。为防止重复发放，我们会保存匿名请求令牌、广告交易 ID 和时间。

4. 可选通知

通知默认关闭。开启后，Google Firebase Cloud Messaging 与 iOS 的 Apple APNs 会处理安装标识符、推送令牌、语言主题订阅和投递信息。在设置中关闭时，应用请求取消订阅并删除 FCM 令牌。也可在系统设置中禁止通知。开发者不另建数据库存储每台设备的推送令牌。目前尚未启用自动通知发送。

5. 账号与购买：启用时适用

当前发布准备版本未启用登录及实际购买。启用购买账号的版本会通过 Supabase 处理邮箱、账号 ID、认证和访问记录、商品及交易 ID、购买环境、已购权益、付费提示余额、使用请求 ID、关卡 ID 和时间，用于认证、购买验证与恢复、防止提示重复扣除。我们不收集银行卡信息。数据库区域为韩国首尔；Supabase 及其分包处理者可能从美国等其他国家提供认证和运维支持。Apple 负责支付及交易验证。需要法律依据时，处理基于履行合同、安全和反欺诈的合法利益、法定义务或可选功能所需的同意。启用购买前会重新核对本说明和数据流程。

6. 服务器保留与跨境处理

账号、权益及付费提示记录在提供和恢复服务所需期间保留；收到删除请求后删除不再需要的信息。交易争议或法定保留所需记录仅在必要范围内保留，并向申请人说明理由和适用期限。删除账号不会删除商店交易记录。Google/Firebase、Apple、Supabase、GitHub 和邮件服务商可能依照各自政策及适用保障措施，在韩国、美国等用户所在国之外处理信息。跨境处理详情及权利请求可通过邮件咨询。

7. 支持与服务提供者

您发邮件时，我们收到邮箱地址、正文及自愿提供的附件，仅用于回复和解决问题。请勿发送密码、验证码或银行卡资料。邮件使用 Gmail，网站使用 GitHub Pages。本页面没有广告、分析脚本或提交表单。GitHub 可能为托管和安全处理 IP 地址与访问日志。Apple、Google、GitHub 和设备备份服务按照各自政策处理信息，可能在美国等境外地区处理。我们不自行上传本地游戏存档；操作系统备份单独管理。

8. 保存与删除

本地数据保留至应用存储被清除。iOS 请删除应用（仅卸载应用可能保留数据），Android 请清除应用存储，网页版请清除对应网站数据。设备及云备份需另行管理。支持信息仅在处理请求所需期间保留，之后不再需要时删除。法律或争议处理要求保留的，将按需说明理由和适用期限。服务提供者的记录遵循其自身保留政策。

9. 权利与处理依据

根据当地法律，您可要求访问、更正、删除、可迁移副本、限制处理、反对、撤回同意或对决定提出申诉。行使权利不会受到歧视，也可向当地数据保护机构投诉。我们可能进行适度的身份验证。需要法律依据时，基于回应服务请求、解决问题的正当利益、法律义务或必要同意处理支持信息。撤回不影响此前合法处理。

10. 儿童、安全与更新

游戏不要求提供个人信息。我们不会故意索取儿童信息；监护人可就儿童向支持邮箱发送的信息联系我们。我们限制信息访问并采取合理保护措施，但不保证绝对安全。重大变更会更新日期，并依法通知或征求同意。
