개인정보처리방침

시행 / 수정: 2026년 9월 16일

1. 운영자와 적용 범위

대한민국의 넥스트 스튜디오(Next Studio)가 하시(com.osj.hashi)를 운영합니다. 이 방침은 앱과 이 지원 웹사이트에 적용됩니다. 개인정보 문의: dhalska2@gmail.com.

2. 기기 내 게임 데이터

퍼즐 진행, 시간, 다리 배치, 완료 기록, 되돌리기, 무료 힌트, 언어·테마·진동·오류 표시 설정은 기기에 저장됩니다. 전체 게임 진행을 서버에 동기화하지 않습니다. 웹 미리보기에는 모바일 광고·푸시·구매 기능이 없습니다. 별도의 Firebase Analytics나 Crashlytics는 사용하지 않습니다.

3. 광고와 개인정보 선택

모바일 앱은 Google AdMob 전면 광고와 선택형 보상 광고를 사용합니다. 광고 SDK는 IP 주소와 그로부터 추정한 대략적 위치, 기기·광고 식별자, 광고 조회·클릭 등의 상호작용, 진단 정보 및 동의 상태를 광고 제공·측정·부정 이용 방지에 처리할 수 있습니다. 정확한 위치 권한은 요청하지 않습니다. 지역과 선택에 따라 동의 메시지를 표시하며, 필요한 경우 설정의 광고 개인정보 옵션에서 선택을 변경할 수 있습니다. 맞춤 광고 거부가 모든 기술 데이터 처리를 중단하는 것은 아닙니다. 광고 목적 공유가 현지 법률상 판매·공유에 해당할 수 있으므로 데이터 수집·공유가 없다고 주장하지 않습니다. 해당 거부권은 동의 화면이나 이메일로 행사할 수 있습니다. 보상형 광고 힌트는 Google의 서명된 서버 알림을 확인한 뒤 지급합니다. 중복 지급을 막기 위해 익명 요청 토큰, 광고 거래 ID와 시간을 서버에 보관합니다.

4. 선택형 알림

알림은 기본적으로 꺼져 있습니다. 허용하면 Google Firebase Cloud Messaging과 iOS의 Apple APNs가 설치 식별자, 푸시 토큰, 선택 언어에 따른 주제 구독 및 전달 정보를 처리합니다. 설정에서 끄면 앱은 구독 해제와 FCM 토큰 삭제를 요청합니다. OS에서도 알림을 차단할 수 있습니다. 개발자가 기기별 푸시 토큰을 별도 DB에 저장하지는 않습니다. 현재 자동 알림 발송은 활성화되지 않았습니다.

5. 계정과 구매: 활성화되는 경우

현재 배포 준비 빌드의 로그인·실제 구매는 비활성화되어 있습니다. 활성화된 버전에서 구매 계정을 사용하면 이메일, 계정 ID, 인증·접속 기록, 상품·거래 ID, 구매 환경, 구매 권한, 유료 힌트 잔액과 사용 요청 ID·퍼즐 ID·시각을 Supabase에 처리하여 인증, 구매 검증·복구와 중복 차감을 방지합니다. 결제 카드 정보는 수집하지 않습니다. DB 지역은 한국 서울이며, Supabase 및 하위 처리업체의 인증·운영 지원은 미국 등 국외에서 이루어질 수 있습니다. Apple은 결제와 거래 검증을 처리합니다. 해당 기능 제공은 계약 이행, 보안·부정 이용 방지는 정당한 이익, 필수 기록은 법적 의무, 선택 기능은 필요한 경우 동의를 근거로 합니다. 구매 기능은 이 데이터 처리 안내를 갱신·검증한 뒤 활성화합니다.

6. 서버 데이터 보유와 국외 처리

계정·구매 권한·유료 힌트 기록은 서비스를 제공하고 복구하는 동안 보유하며, 삭제 요청 시 불필요한 정보를 삭제합니다. 거래 분쟁·법적 보존 의무가 있는 항목은 필요한 범위에서만 보유하고 요청자에게 사유와 적용 기간을 안내합니다. 계정 삭제가 스토어 거래 기록까지 삭제하지는 않습니다. Google/Firebase, Apple, Supabase, GitHub 및 이메일 제공업체는 한국·미국 등 이용자 국가 밖에서 정보를 처리할 수 있으며 각 제공업체 정책과 적용되는 보호 조치에 따릅니다. 구체적인 이전 정보와 권리 행사는 아래 이메일로 문의할 수 있습니다.

7. 문의와 웹사이트 제공업체

문의 이메일을 보내면 이메일 주소, 문의 내용과 선택적으로 보낸 첨부파일을 답변·문제 해결에 사용합니다. 비밀번호·인증 코드·카드 정보는 보내지 마세요. 문의에는 Gmail, 웹페이지 호스팅에는 GitHub Pages를 사용합니다. 이 페이지에는 광고·분석 스크립트·입력 폼이 없습니다. GitHub는 호스팅·보안을 위해 IP 주소와 접속 기록을 처리할 수 있습니다. Apple·Google·GitHub·기기 백업 서비스가 직접 처리하는 정보에는 각 정책이 적용됩니다. 제공업체는 미국 등 이용자 국가 외에서도 처리할 수 있습니다. 운영자가 로컬 게임 기록을 이들 서버로 전송하지는 않으며 운영체제 백업은 별도 설정을 따릅니다.

8. 보유 및 삭제

로컬 정보는 앱 저장 공간이 삭제될 때까지 남습니다. iOS에서는 앱 삭제(앱 정리하기는 데이터를 남길 수 있음), Android에서는 앱 저장 공간 삭제, 웹 게임에서는 브라우저의 해당 사이트 데이터 삭제를 이용하세요. 기기·클라우드 백업은 별도로 관리하세요. 문의 정보는 요청 처리에 필요한 동안 보유하고 불필요해지면 삭제합니다. 법령·진행 중인 분쟁으로 필요한 경우 필요한 범위에서 보유하며 요청 시 사유와 적용 기간을 안내합니다. 제공업체가 직접 관리하는 정보는 각 보유 정책을 따릅니다.

9. 이용자 권리와 처리 근거

적용 법령에 따라 열람, 정정, 삭제, 이동 가능한 사본, 처리 제한, 이의 제기, 동의 철회 또는 결정에 대한 재검토를 요청할 수 있습니다. 권리 행사에 따른 차별 없이 문의할 수 있으며 관할 개인정보 감독기관에 민원을 제기할 수 있습니다. 필요한 범위에서 본인 확인을 요청할 수 있습니다. 처리 근거가 필요한 지역에서는 서비스 요청에 대한 응답, 문제 해결의 정당한 이익, 법적 의무 또는 필요한 동의를 근거로 문의 정보를 처리합니다. 동의 철회는 철회 전 적법한 처리에 영향을 주지 않습니다.

10. 아동·보호 조치·변경

게임에 개인정보 입력이 필요하지 않습니다. 아동의 개인정보를 고의로 요청하지 않으며, 아동이 문의 과정에서 보낸 정보는 보호자가 연락하여 확인·삭제를 요청할 수 있습니다. 문의 정보의 접근을 제한하는 등 합리적 보호 조치를 취하지만 완전한 보안을 보장하지는 않습니다. 중요한 변경 시 날짜와 내용을 갱신하고 법령상 필요한 안내·동의 절차를 제공합니다.
