Privacidad

Vigente / actualizado: 16 de septiembre de 2026

1. Responsable y alcance

Next Studio, Corea del Sur, opera Hashi (com.osj.hashi). Esta política cubre la app y este sitio de soporte. Contacto: dhalska2@gmail.com.

2. Datos de juego en el dispositivo

El progreso, el tiempo, los puentes, las partidas completadas, el historial de deshacer, las pistas gratuitas y los ajustes de idioma, tema, vibración y errores se guardan en el dispositivo. No sincronizamos el progreso completo con el servidor. La vista previa web no incluye anuncios móviles, notificaciones push ni compras. No utilizamos SDK independientes de Firebase Analytics ni Crashlytics.

3. Publicidad y opciones de privacidad

La app móvil utiliza anuncios intersticiales de Google AdMob y anuncios con recompensa opcionales. El SDK publicitario puede tratar la IP y la ubicación aproximada deducida, identificadores del dispositivo y publicitarios, visualizaciones y clics, diagnósticos y preferencias de consentimiento para ofrecer y medir anuncios y prevenir el fraude. No pedimos acceso a la ubicación precisa. Los avisos de consentimiento dependen de la región y de tus elecciones; cuando corresponda, puedes modificarlas en las opciones de privacidad publicitaria de Ajustes. Rechazar anuncios personalizados no detiene todo tratamiento técnico. La comunicación de datos publicitarios puede constituir venta o intercambio según la ley local; no afirmamos que no se recopilen ni compartan datos. Puedes ejercer los derechos de exclusión aplicables mediante esos controles o por correo. Las pistas por anuncios se entregan tras verificar en nuestro servidor la respuesta firmada de Google. Guardamos un identificador de solicitud seudónimo, el ID de transacción del anuncio y la hora para evitar duplicados.

4. Notificaciones opcionales

Están desactivadas por defecto. Al activarlas, Google Firebase Cloud Messaging y Apple APNs en iOS tratan identificadores de instalación, tokens push, suscripciones a temas por idioma e información de entrega. Desactivarlas en Ajustes solicita la baja del tema y la eliminación del token FCM. También puedes bloquearlas en el sistema operativo. No mantenemos una base de datos aparte con tokens por dispositivo. El envío automático de notificaciones aún no está activo.

5. Cuentas y compras

Supabase trata correo, ID de cuenta, registros de autenticación y acceso, IDs de producto y transacción, entorno de compra, derechos adquiridos, saldo de pistas pagadas, ID de solicitud de uso, ID de puzle y hora para autenticar, verificar, recuperar compras y evitar descuentos duplicados de pistas. No recopilamos datos de tarjetas. La base de datos está en Seúl, Corea del Sur; Supabase y sus subencargados pueden prestar apoyo de autenticación y operación desde otros países, incluido EE. UU. Apple procesa pagos y verifica transacciones. Cuando se exige una base jurídica, se aplica la ejecución del contrato, el interés legítimo en seguridad y prevención del fraude, obligaciones legales o el consentimiento para funciones opcionales.

6. Conservación en servidor y transferencias

Los registros de cuenta, derechos y pistas pagadas se conservan mientras sean necesarios para prestar y recuperar el servicio; eliminamos los datos innecesarios tras una solicitud. Solo conservamos lo necesario para disputas o deberes legales, explicando al solicitante el motivo y el plazo aplicable. Eliminar la cuenta no borra las transacciones de la tienda. Google/Firebase, Apple, Supabase, GitHub y los proveedores de correo pueden tratar datos fuera de tu país, incluidos Corea del Sur y EE. UU., conforme a sus políticas y a las garantías aplicables. Escríbenos para conocer los detalles de las transferencias o ejercer tus derechos.

7. Soporte y proveedores

Usamos el correo, mensaje y adjuntos que envías solo para responder y resolver tu solicitud. No envíes contraseñas, códigos ni tarjetas. Usamos Gmail y GitHub Pages; estas páginas no contienen anuncios, analítica ni formularios. GitHub puede tratar IP y registros para alojamiento y seguridad. Apple, Google, GitHub y los servicios de copia de seguridad aplican sus propias políticas y pueden tratar datos fuera de tu país, incluido Estados Unidos. No subimos partidas a esos proveedores; las copias del sistema se gestionan por separado.

8. Conservación y eliminación

Los datos locales permanecen hasta borrar el almacenamiento: elimina la app en iOS (descargarla conservando datos no basta), borra datos en Android o datos del sitio del juego web. Gestiona las copias por separado. Conservamos consultas mientras sean necesarias y después las eliminamos. Si la ley o un litigio exige retención, explicaremos motivo y plazo aplicable. Los registros de los proveedores siguen sus propias políticas.

9. Derechos y bases jurídicas

Según la ley local, puedes solicitar acceso, rectificación, eliminación, copia portable, limitación, oposición, retirada del consentimiento o recurso. No discriminamos por ejercer derechos; puedes reclamar a la autoridad local. Podemos verificar tu identidad de forma proporcionada. Cuando se exige una base jurídica, usamos la atención de tu solicitud, el interés legítimo en resolver problemas, obligaciones legales o consentimiento cuando proceda. Retirarlo no afecta al tratamiento previo lícito.

10. Menores, seguridad y cambios

Jugar no requiere datos personales. No solicitamos deliberadamente datos de menores; sus tutores pueden contactarnos sobre información enviada al soporte. Limitamos el acceso y aplicamos medidas razonables, sin garantizar seguridad absoluta. Publicaremos cambios importantes con fecha nueva y los avisos o consentimientos exigidos.
