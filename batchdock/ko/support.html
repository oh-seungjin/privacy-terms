사진 준비와 내보내기

사진 또는 파일을 가져와 출력 규격을 설정하고 처리하세요. 결과를 누르면 비교할 수 있습니다. 사진 보관함·파일에 저장하거나 시스템 공유창으로 전달하세요. ZIP은 Pro 기능입니다.

작업 중단과 재시도

앱을 다시 열어 미완료 결과를 재시도하세요. 파일이 남아 있는 성공 결과는 유지됩니다. 처리 중 앱을 열어 두세요. 무제한 백그라운드 처리는 지원하지 않습니다. 여유 공간을 확보하고 메모리가 부족하면 사진 수를 줄이세요.

구매와 복원

같은 스토어 계정으로 설정의 구매 복원을 누르세요. 가격을 불러오지 못하면 인터넷을 확인하고 스토어 다시 연결을 사용하세요. iOS와 Android 구매는 별개입니다. 환불은 해당 스토어에서 진행합니다. 비밀번호·전체 영수증·카드 정보를 문의에 포함하지 마세요.

데이터 삭제

작업 공간 비우기는 작업 사본·결과만 삭제하고 프리셋은 유지합니다. 프리셋은 별도로 삭제하고 모든 로컬 데이터는 앱 삭제 또는 앱 데이터 삭제로 제거하세요. 내보낸 파일·원본은 각 저장 위치에서 직접 삭제합니다. BatchDock 계정은 없습니다. 진단 정보나 문의 내역 삭제는 이메일로 요청하세요.
