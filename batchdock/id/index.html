BatchDock

Ubah ukuran, tambahkan tanda air, dan konversi foto langsung di perangkat Anda.

JPG · PNG · WebP

Gratis · 5 foto · 1 keluaran · 1 preset

Hingga 200 foto, 3 ukuran keluaran, preset, nama bernomor, dan ekspor ZIP teratur. Sekali beli, tanpa langganan.

Setiap file masukan maksimal 150 MB. Sisi terpanjang dinormalisasi hingga maksimal 4096 piksel. Simpan file aslinya.

Foto diproses di perangkat, tanpa unggahan foto, akun, iklan, atau pelacakan. Salinan kerja tetap ada sampai ruang kerja dikosongkan. Pembelian menggunakan toko dan server verifikasi. Crashlytics mengumpulkan diagnostik teknis; isi dan nama foto tidak sengaja dicatat.
