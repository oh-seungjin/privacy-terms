Kebijakan privasi

Foto diproses di perangkat, tanpa unggahan foto, akun, iklan, atau pelacakan. Salinan kerja tetap ada sampai ruang kerja dikosongkan. Pembelian menggunakan toko dan server verifikasi. Crashlytics mengumpulkan diagnostik teknis; isi dan nama foto tidak sengaja dicatat.

Firebase Crashlytics

Firebase Crashlytics mengumpulkan jejak kesalahan, versi aplikasi dan sistem, informasi perangkat, serta ID instalasi untuk mendiagnosis masalah, bukan pelacakan iklan. Penghapusan dimulai setelah penyimpanan selama 90 hari. Versi distribusi mengumpulkannya otomatis tanpa tombol penonaktifan di aplikasi.

Apple App Store · Supabase

Verifikasi pembelian menggunakan server Next Studio yang dihosting Supabase. Bukti pembelian bertanda tangan diverifikasi dengan Apple. Server menyimpan hash transaksi yang tidak dapat dibalik, toko, lingkungan, status pengembalian dana, dan waktu verifikasi, tanpa menyimpan bukti asli atau foto. Hash dan pencabutan disimpan untuk mencegah pembukaan kembali setelah pengembalian dana. Hubungi kami untuk permintaan penghapusan.

Kosongkan ruang kerja

Mengosongkan ruang kerja menghapus salinan dan hasil, tetapi menyimpan preset dan logo. Menghapus aplikasi atau datanya menghapus data lokal, bergantung pada cadangan sistem. File asli dan ekspor tetap di tempatnya.

Lokasi dan metadata lainnya dihapus. File asli tidak diubah.
