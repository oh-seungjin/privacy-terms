홈(마케팅), 개인정보처리방침, 이용약관, 지원, 데이터 삭제 안내를 8개 언어로 제공합니다. 앱은 현재 한국어 UI만 제공합니다.
내용 근거: 익명 Supabase 로그인(서버 힌트·구매 검증 기록), Google AdMob(비개인 맞춤 광고만, UMP), Firebase Crashlytics(릴리스만), ATT 미사용, 계정·푸시 없음.
`generate_pages.py`가 `translations.json`에서 40개 정적 페이지를 만듭니다(`python3 generate_pages.py`). 언어 번역은 영어 원문 기준 교정 전 초안이므로 법적 검토가 필요하면 별도로 받으세요.
