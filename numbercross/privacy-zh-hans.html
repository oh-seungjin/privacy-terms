首页隐私政策服务条款帮助与支持数据删除

隐私政策

生效/更新日期 2026年10月31日

1. 运营方与适用范围

Next Studio(韩国)运营面向 iOS 和 Android 的数学填字谜题 Number Cross(com.osj.numbercross)。本政策适用于应用和本支持网站。隐私联系邮箱:dhalska2@gmail.com。

2. 保存在设备上的游戏数据

谜题进度、已通关关卡、提示使用次数、当前棋盘和设置(主题、触感、输入选项)保存在您的设备上。删除应用即可清除,这些数据不会作为存档上传。

3. 提示、奖励与购买(我们的服务器)

应用以匿名方式登录我们的服务器,不要求姓名、邮箱或密码。我们保存匿名用户 ID、提示余额及发放与消耗记录(请求 ID 和时间)、激励广告确认记录,以及购买记录(商品 ID、商店、环境,以及交易或购买令牌的单向哈希)。提示仅由服务器发放和扣除,因此使用提示需要联网;普通游玩可离线进行。支付由 Apple 或 Google Play 处理,我们不会收到银行卡信息。购买或恢复“移除广告”时,应用会把商店购买凭证发送到服务器,服务器向 Apple 或 Google 验证后才会生效。

4. 广告与隐私选择

应用展示 Google AdMob 插屏广告和可选的激励广告。我们只请求非个性化广告,并在需要的地区显示 Google 同意提示(UMP),您可在设置中更改选择。广告 SDK 可能处理 IP 地址及据此推断的大致位置、设备和广告标识符(Android 上为广告 ID)、广告展示与点击、诊断信息和您的同意选择,用于投放、衡量广告和防止欺诈。我们不使用 App Tracking Transparency,也不跨其他公司的应用追踪您。对于激励广告,服务器会保存匿名化的凭证令牌、广告交易 ID 和时间,以防重复发放奖励。广告相关信息披露在当地法律下可能构成“出售或共享”;我们不声称不收集任何数据。

5. 崩溃报告

发布版会把崩溃和错误报告发送到 Google Firebase Crashlytics(堆栈信息、设备型号、操作系统、应用版本、每次安装的标识符),仅用于修复缺陷。调试版不发送报告。我们不使用 Firebase Analytics。

6. 服务器位置、保存期限与服务提供方

我们的数据库(Supabase)位于韩国首尔;Supabase 及其分包处理方可能从包括美国在内的其他国家提供运维支持。支付和广告使用 Apple 和 Google,崩溃报告使用 Google Firebase,本网站使用 GitHub Pages。匿名服务器记录在应用使用期间保存。购买记录(交易哈希、商品、时间,不含个人信息)可能为退款处理和会计而保留。设备数据随删除应用而清除。

7. 您的权利与删除

您可以通过邮件 dhalska2@gmail.com 请求访问、更正或删除我们持有的与您的匿名 ID 相关的数据,或反对处理。由于 ID 是匿名的,我们可能需要应用版本和您使用的时间来查找;请勿发送密码或银行卡信息。处理依据为合同履行(运营游戏和验证购买)、安全、防欺诈和修复缺陷方面的正当利益、法律义务,以及必要时的同意(广告选择)。具体步骤请见“数据删除”页面。

8. 儿童与变更

Number Cross 不面向 13 岁以下儿童,我们不会明知而收集其个人信息。如本政策变更,我们会更新上述日期,重大变更会在应用或本网站中通知。
